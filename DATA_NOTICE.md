# Data and responsible-use notice

MapleGuard uses deterministic, fully synthetic transaction records. It does not contain customer, bank, credit-bureau, or merchant data. Names, account numbers, card numbers, addresses, and other direct identifiers are never generated.

The project is a portfolio demonstration of data engineering, model evaluation, risk operations, and business-intelligence practices. It is not a production fraud system, credit-decision engine, or substitute for legal, compliance, model-risk, privacy, or human review.

The synthetic label is intentionally created from known behavioural patterns so the pipeline can be tested end to end. Real-world deployment would require representative data, bias and drift testing, privacy review, security controls, explainability review, threshold governance, adverse-impact testing, and ongoing human oversight.
